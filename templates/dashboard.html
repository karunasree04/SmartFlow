Algorithms Reference

Implemented in Python (algorithms.py) and C (programs.c)

📦 Priority Queue — Max-Heap

Lane vehicle counts × 10 = priority score. Pushed into max-heap. get_highest_priority() pops the most congested lane in O(log n). That lane gets the green signal.

⏱ Insert: O(log n) ⏱ Extract-Max: O(log n) 💾 Space: O(n)

🗺️ Dijkstra's Shortest Path

Models road network as weighted graph. Greedily picks nearest unvisited node using min-heap, relaxes edges to find shortest path. Smart Route adds congestion penalty to avoid heavy lanes — exactly like Google Maps.

⏱ Time: O((V+E) log V) 💾 Space: O(V)

👁 YOLOv5 Object Detection

Pretrained on COCO dataset. Scans each frame once (You Only Look Once), returns bounding boxes + class labels. Vehicle center-X mapped to lane. Ambulance triggers emergency override.

⏱ Real-time per frame 💾 YOLOv5s: ~14MB
