Project Features

A complete traffic management platform — signal control, smart routing, history analytics, and more.

🎥

Video-Based Detection

Upload traffic footage. YOLOv5 detects cars, buses, trucks, motorbikes and ambulances frame-by-frame.

🚦

Dynamic Signal Control

Priority Queue (Max-Heap) picks the most congested lane in O(log n). That lane gets the green signal.

🚑

Ambulance Override

Emergency vehicles trigger a flashing red alert and instantly set all lanes to green.

🗺️

Dijkstra finds shortest + smart routes on a visual road map. Smart Route avoids congested lanes — just like Google Maps avoids traffic.

📐 DAA Core

Algorithms Used

Two classic DAA algorithms implemented end-to-end in Python and C — with visual demonstration.

📦

Priority Queue (Max-Heap)

Lane counts → priority scores → max-heap → pop most congested lane in O(log n) → green signal decision.

Time: O(log n) Space: O(n)
🗺️

Dijkstra's Algorithm

Road network as weighted graph. Greedy min-heap finds shortest path + smart congestion-aware route on a visual Google Maps style interface.

Time: O((V+E)logV) Space: O(V)
🔧

Dual Implementation — Python + C

Both algorithms in algorithms.py for the live app, and manually in programs.c with heapify_up, heapify_down, and adjacency matrix Dijkstra from scratch — proving understanding at both high and systems level.
